# Panduan Import Kamus EMI

Unduh template Excel `.xlsx` dari halaman **Impor Kamus**. Template berisi dua sheet:

- `Kosakata` untuk kata utama.
- `Contoh Kalimat` untuk contoh yang dihubungkan melalui kata Mekongga terkait.

Ketentuan:

- Nama sheet dan header tidak boleh diubah.
- Isi kedua jenis data dalam satu file Excel `.xlsx`.
- Kategori Kosakata harus sudah dibuat dan berstatus aktif.
- Kata Mekongga terkait pada sheet `Contoh Kalimat` harus tersedia pada sheet `Kosakata` atau sudah ada di kamus.
- Periksa ringkasan terpisah Kosakata dan Contoh Kalimat sebelum konfirmasi.
- Baris invalid tidak masuk ke kamus final. Sheet dan nomor baris tersedia pada daftar error.
