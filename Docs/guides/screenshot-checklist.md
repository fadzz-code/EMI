# Checklist Screenshot Buku Panduan EMI

## Aturan Screenshot

- Gunakan domain https://emi-kolaka.id.
- Gunakan browser desktop.
- Zoom browser 100%.
- Ukuran jendela konsisten, disarankan 1440x900 atau 1366x768.
- Gunakan data demo dari seeder.
- Jangan menampilkan password.
- Jangan menampilkan token atau data sensitif.
- Pastikan halaman sudah selesai loading sebelum screenshot.
- Gunakan nama file huruf kecil, kebab-case, dan berurutan.

## Akun Demo

Admin: admin.demo@emi.local

Guru: guru.rina@emi.local atau guru.arman@emi.local

Siswa: siswa.nanda@emi.local atau siswa.mira@emi.local

Password mengikuti password demo yang diberikan pengelola sistem.
