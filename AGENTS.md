## Phase Isolation

- Kerjakan hanya fase yang disebut secara eksplisit dalam prompt.
- Roadmap bukan perintah untuk mengerjakan semua fase.
- Baca hanya file phase yang disebutkan dalam prompt aktif.
- Jangan lanjut ke fase berikutnya secara otomatis.
- Setelah Definition of Done fase aktif terpenuhi, berhenti.
- Jangan commit, merge, push, atau berpindah branch kecuali diminta.
